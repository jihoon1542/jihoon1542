## Projects

### 🎓 GRANA
**Graduate + Navigation**

대학생이 자신의 졸업요건을 쉽게 파악하고,
졸업까지 남은 학점과 이수 가능한 과목을 확인할 수 있도록 돕는 개인 맞춤형 졸업 플래너입니다.

#### 주요 기능
- 학과 / 입학년도 / 졸업예정 시점에 따른 졸업요건 분석
- 공학교육인증 적용 여부 자동 판정
- 전공 / 핵심교양 / 일반교양 등 영역별 이수 현황 분석
- 졸업까지 남은 학점 계산
- 이미 이수한 과목을 제외한 수강 가능 과목 안내
- 에브리타임 시간표 캡처 기반 이수과목 분석
- AI 졸업 도우미를 통한 교과목 및 졸업요건 질의응답

> **시간표에서 졸업까지, GRANA가 길을 안내합니다.**
